This is a project to create a REST web service that can be accessed by a script in digiCamControl as external object. Build and run this project; it has a single web page. The page contains a description how to work with the object in digiCamControl, and shows the state of the object as exposed by the web service.

The project can also be published; it creates an executable in *Examples\Tcl scripts\Webserver*:
- Run that executable
- Open a browser for [http://localhost:5000/](http://localhost:5000/)
- Import *Tcl scripts\External - WebService.dccproject.zip* project in digiCamControl
- Open the *Script execution* window, find the script via the *Script* menu, and run it.
